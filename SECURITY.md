# Security policy

## Supported versions

BinaryHunter is currently a preview project. Security fixes are applied to the
latest commit on the `main` branch and the current `1.0.x` source line.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** action in the repository Security tab to
send a private report. Include the affected component, impact, reproduction steps
and a minimal proof of concept when safe to do so.

Do not disclose a vulnerability in a public issue before a fix is available. Do not
attach ECU firmware, VINs, credentials, customer data or proprietary calibration
definitions to a public issue or pull request.

Reports will be reviewed as availability permits. Acknowledgement does not imply a
guaranteed resolution timeline while the project remains in preview.
